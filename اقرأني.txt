مينا ستودنت AI — النسخة السحابية/PWA
====================================

مهم قبل النشر
-------------
هذه الحزمة تجهّز أتمتة النشر، لكنها ليست موقعًا منشورًا بعد. يجب إنشاء مشروع Supabase وإضافة المتغيرات والأسرار إلى إعدادات GitHub مرة واحدة. لا تضع كلمات مرور أو مفاتيح API السرية في ملفات المستودع أو المحادثات.

حماية الحسابات
--------------
- لا يوجد زر إعداد أدمن من المتصفح.
- بريد الأدمن المسموح محدد في supabase/schema.sql داخل admin_allowlist. إنشاء حساب الأدمن يكون من شاشة التسجيل المعتادة باستخدام هذا البريد، ثم تأكيد البريد وتسجيل الدخول.
- صلاحية الأدمن يفرضها الخادم وقاعدة البيانات (RLS)، وليس مجرد اسم أو بريد محفوظ في JavaScript.
- حسابات الطلاب تبدأ Pending. يستطيع الأدمن قبولها أو رفضها أو إيقافها.
- الحساب المرفوض أو الموقوف يظل له سجل حالة، لذلك تظهر له رسالة رفض/إيقاف عند تسجيل الدخول بدلًا من السماح له بإنشاء حساب محلي جديد.
- رمز الموافقة عشوائي من الخادم وتنتهي صلاحيته بعد 30 دقيقة، مع إيقاف الرمز بعد خمس محاولات خاطئة. من لوحة الأدمن يمكن نسخ الرمز أو فتح محادثة واتساب مع الطالب برسالة جاهزة. زر واتساب لا يرسل تلقائيًا؛ يجب على الأدمن مراجعة الرسالة والضغط على إرسال. الإرسال التلقائي يحتاج ربطًا مستقلًا بواجهة WhatsApp Business الرسمية.
- تم استخدام رقم الهاتف والمحافظة والعنوان. لم نضف الرقم القومي/جواز السفر لأنهما بيانات حساسة لا يحتاجها تطبيق مذاكرة.

الإعداد والنشر الآلي عبر GitHub Actions
--------------------------------------
هذه الأتمتة تجعل النشر مجانيًا ضمن حدود الخطط المجانية، لكنها تحتاج إعداد حساباتك الخاصة مرة واحدة. لا أستطيع إنشاء مشروع داخل حسابك أو استخدام تسجيل دخولك من هذه المحادثة.

1) أنشئ مشروع Supabase جديدًا على الخطة المجانية. رابط الموقع المتوقع للمستودع الحالي هو:
   https://minaratebnabilkhella.github.io/Ai-MIna/
2) افتح المستودع على GitHub ثم Settings > Secrets and variables > Actions.
3) في Variables أضف:
   - SUPABASE_URL: رابط المشروع، مثل https://ulvkvvjjegiecvkjuiag.supabase.co
   - SUPABASE_ANON_KEY: المفتاح العام anon/publishable من إعدادات API في Supabase.
   - SUPABASE_PROJECT_REF: معرّف المشروع: ulvkvvjjegiecvkjuiag (من رابط لوحة Supabase).
   - SUPPORT_WHATSAPP (اختياري): رقم الدعم الدولي بلا + أو صفر البداية.
   - MINA_APP_URL (اختياري): رابط GitHub Pages النهائي.
4) في Secrets أضف:
   - SUPABASE_ACCESS_TOKEN: رمز الوصول الشخصي الذي تنشئه داخل حساب Supabase. لا ترسله في المحادثات.
   - SUPABASE_DB_PASSWORD: كلمة مرور قاعدة البيانات التي اخترتها عند إنشاء المشروع.
   - GEMINI_API_KEY: مفتاح Gemini جديد بعد إلغاء المفتاح الذي سبق مشاركته.
   - YOUTUBE_API_KEY: مفتاح YouTube Data API v3 لتفعيل ترشيح فيديوهات محددة. إن لم تضفه، لن تعمل الترشيحات المحددة حتى تضيفه لاحقًا.
5) افتح Settings > Pages واختر GitHub Actions كمصدر للنشر.
6) بعد استخراج ZIP على Windows، شغّل رفع-النسخة-إلى-GitHub.bat. راجع التحذير، ثم اكتب PUBLISH للموافقة على استبدال الملفات المتتبعة في main. يتطلب Git for Windows وتسجيل الدخول المعتاد إلى GitHub. لا تشارك أي مفاتيح أو رموز وصول في المحادثات.
7) عند رفع الملفات، ستعمل تلقائيًا الـWorkflows الخاصة بفحص الملفات، ونشر قاعدة Supabase ودوالها، ونشر الموقع. إذا كانت الإعدادات ناقصة، سيظهر الفشل داخل GitHub Actions بدل نشر نسخة معطلة.
8) افتح Supabase > Authentication > URL Configuration، واضبط Site URL وRedirect URLs على رابط GitHub Pages أعلاه، وفعّل تأكيد البريد الإلكتروني.
9) بعد نجاح نشر الموقع، سيبني Workflow النشر ملف EXE تلقائيًا. من نفس تشغيل Workflow في Actions نزّل Artifact باسم Mina-Student-AI-Windows-Installer، وهو متاح 30 يومًا.

إذا كنت قد شغّلت supabase/schema.sql يدويًا في قاعدة البيانات نفسها، راجع حالة migrations قبل تشغيل Workflow لأول مرة؛ الملف supabase/migrations/20261020000000_initial_schema.sql هو مسار النشر الآلي.

رفع الملفات الجاهزة من Windows
-----------------------------
الملف رفع-النسخة-إلى-GitHub.bat يرفع النسخة إلى المستودع MinaRatebNabilKhella/Ai-MIna باستخدام Git على جهازك. سيطلب تأكيدًا صريحًا قبل استبدال الملفات المتتبعة في فرع main. لا يقرأ ملفات .env ولا يرفعها.

الحدود الحالية للاستهلاك
------------------------
- الطلاب: 20 طلب ذكاء اصطناعي يوميًا، و10 طلبات ترشيح YouTube يوميًا.
- الأدمن: 100 طلب لكل خدمة يوميًا.
- يحجز الخادم الطلب داخل جدول usage_daily بعملية ذرية حتى لا يؤدي إرسال عدة طلبات متزامنة إلى تجاوز الحد اليومي.
- الحد الأقصى 20 رسالة محفوظة بالسياق، و3000 حرف للرسالة، و12000 حرف إجماليًا، مع تقييد طول الإجابة.
- Gemini الافتراضي: gemini-3.8-flash. يمكن ضبطه من أسرار الخادم، لا من حسابات الطلاب.
- YouTube يحتاج YouTube Data API v3 مفعّلًا ومفتاحًا سريًا على الخادم. لو لم يتم ضبطه، ستظهر روابط بحث بديلة ورسالة توضح الإعداد الناقص.

رفع الواجهة على GitHub Pages
----------------------------
1) ارفع جميع ملفات المجلد إلى المستودع الرئيسي (main).
2) في إعدادات المستودع: Settings > Pages > Build and deployment، اختر GitHub Actions.
3) عند كل Push إلى main سيشغّل الملف .github/workflows/deploy-pages.yml النشر تلقائيًا.
4) افتح الرابط الذي يعرضه GitHub Pages. يجب أن يعمل من HTTPS حتى يعمل تثبيت PWA.

الأندرويد والآيفون والكمبيوتر
-----------------------------
- هذا المشروع PWA: على Android افتح رابط HTTPS واختر Install app / Add to Home screen.
- على iPhone افتحه في Safari ثم Share > Add to Home Screen.
- على الكمبيوتر يمكن تثبيته كتطبيق من قائمة المتصفح عند ظهور Install.
- بعد نجاح نشر GitHub Pages، سيبني Workflow النشر ملف EXE تلقائيًا ويضعه كـ Artifact باسم Mina-Student-AI-Windows-Installer لمدة 30 يومًا. يوجد أيضًا Workflow منفصل لبنائه يدويًا عند الحاجة.
- على Android وiPhone المسار المتاح هنا هو PWA (إضافة للشاشة الرئيسية). لم تتم إضافة APK أو IPA أصلي؛ ملف IPA يحتاج توقيع وتوزيع Apple، وملف APK يحتاج بناء واختبار Android منفصلين.

بيانات الطلاب والمزامنة
-----------------------
بيانات الطالب (الجدول، المهام، النقاط، الملاحظات والشات المحفوظ) تُحفظ محليًا كنسخة مؤقتة وتُزامَن بجدول student_data بعد الموافقة. يمكن للأدمن تنزيل نسخة JSON لبيانات الطالب من لوحة الإدارة. يستخدم الجدول سياسات RLS؛ الطالب لا يستطيع قراءة بيانات طالب آخر.

قائمة مراجعة قبل الإطلاق العام
------------------------------
- إبطال أي Gemini API Key تمت مشاركته سابقًا، وإنشاء مفتاح جديد، وحفظه كـ Supabase Secret فقط.
- تغيير أي كلمة مرور ظهرت في محادثة أو لقطة شاشة وعدم إعادة استخدامها.
- ضبط Supabase Auth وSite URL والرابط النهائي.
- اختبار التسجيل ببريد طالب، تأكيد البريد، بقاء الحساب Pending، قبول/رفض، رمز موافقة منتهي الصلاحية، إيقاف حساب، ومزامنة حساب بين جهازين.
- اختبار حدود الذكاء الاصطناعي وYouTube على حساب تجريبي قبل توزيع الرابط على الطلاب.
